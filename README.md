
# 📊 Projeto de Análise de Vendas – Loja Fictícia

Este projeto utiliza Python e bibliotecas como Pandas, Matplotlib e Seaborn para analisar os dados de vendas de uma loja fictícia. As análises foram feitas no Google Colab.

Análises Realizadas:
- Preço médio por categoria
- Vendas totais por região
- Vendas por forma de pagamento
- Produtos mais vendidos
- Vendas totais por categoria
- Evolução da receita por mês e ano
- Top 10 produtos mais lucrativos (lucro bruto)
- Comparação de lucro por categoria

Tecnologias Usadas:
- Python 3
- Google Colab
- Pandas
- Matplotlib
- Seaborn
